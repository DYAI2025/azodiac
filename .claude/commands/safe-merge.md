## Context

`gh pr merge --squash --delete-branch` post-checkouts to local main and tries to fast-forward. If the working tree has dirty agent-state files (`.claude/homunculus/observations.jsonl`, `.swarm/memory.db-*`, `ruvector.db`, etc), the pull fails with `Pull mit Rebase nicht möglich: Sie haben Änderungen, die nicht zum Commit vorgemerkt sind`. The PR still merges on GitHub but local repo gets stuck mid-checkout. This skill prevents that.

Observed pattern this session: 8 PRs merged, every single one hit the dirty-state collision. Manual remediation each time: stash → gh pr merge → pull --ff-only.

## Your Task

Squash-merge a GitHub PR cleanly while protecting any dirty agent-state files in the working tree.

### Steps

1. **Pre-flight: identify the PR number** (positional arg `$1`, or ask user if missing).

2. **Stash agent-state churn explicitly by path** — never `git stash` everything (would also stash legitimate uncommitted code):
   ```bash
   git stash push -m "agent-state-pre-pr<N>-merge" -- \
     .claude/homunculus/observations.jsonl \
     .swarm/memory.db-shm \
     .swarm/memory.db-wal \
     ruvector.db 2>&1 | tail -2
   ```
   Files may not exist in every repo — stash silently no-ops missing paths.

3. **Squash-merge via gh CLI** with branch deletion:
   ```bash
   gh pr merge <N> --squash --delete-branch 2>&1 | tail -5
   ```

4. **Fast-forward local main** (gh auto-checks-out to main post-merge):
   ```bash
   git pull --ff-only origin main 2>&1 | tail -3
   ```

5. **Verify state** — recent log + branch confirmation:
   ```bash
   git branch --show-current
   git log --oneline -3
   ```

6. **Optional**: run `npm test` (or detected test command) to confirm the merged PR didn't break baseline.

### Guardrails

- **Never `git stash` without explicit paths.** Stashing everything sweeps up legitimate work-in-progress.
- **Never use `--force` with this skill.** Squash + delete-branch is the only acceptable merge mode here. If a different mode is needed, fall back to manual `gh pr merge`.
- **If pull --ff-only fails** (remote and local genuinely diverged), STOP. Don't auto-rebase — surface to user. Pre-merge state should always be a clean ancestry.
- **Don't pop the stash automatically.** The stashed agent-state churn regenerates from agent activity anyway; popping leaks pre-merge state into post-merge working tree.

### Common follow-up

After 5+ PRs merged via this skill, the stash list accumulates. Manual cleanup:
```bash
git stash list | grep "agent-state-pre-pr"
git stash drop  # repeat to clear oldest
```
