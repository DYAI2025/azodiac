6. **Check listening ports for backdoors**:


7. **Verdict**:
   - **Clean**: Only known IPs, no suspicious processes, no injected crons, no unknown listeners
   - **Suspicious**: Unknown large files or processes → investigate further
   - **Compromised**: Unknown SSH logins, injected crontabs, crypto miners → immediate lockdown

### If Compromised

1. Change SSH keys immediately
2. `ufw deny from <attacker_ip>`
3. Kill malicious processes
4. Remove injected crontabs
5. Check for persistence: `/etc/rc.local`, systemd services, `.bashrc` modifications
6. Consider full reinstall if rootkit suspected

### Guardrails

- `/var/tmp` numeric files are often snap or apt cache — check `file` command before deleting
- `kswapd0` at 0% CPU is normal kernel virtual memory management
- Multiple `Accepted publickey` from the same IP in quick succession is normal (Claude Code SSH commands)
- Fail2Ban logs reset on reboot — check journal if auth.log is empty
- High load average alone is NOT a compromise indicator — check process list first
