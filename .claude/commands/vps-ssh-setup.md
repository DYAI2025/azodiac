## Context
You are helping set up SSH access to the user's VPS at srv1308064.hstgr.cloud. This involves generating SSH keys, copying them to the VPS, setting correct permissions, and testing the connection.

## Your Task

Automate SSH connection setup and troubleshooting for VPS access. This skill handles the complete workflow from key generation to connection verification.

### Steps

1. **Check Existing SSH Setup**
   - Check if SSH key already exists: `ls -la ~/.ssh/id_ed25519*`
   - If exists, ask user if they want to use existing key or generate new one

2. **Generate SSH Key (if needed)**
   ```bash
   # Generate key without passphrase for non-interactive use
   ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519 -N "" -C "$(whoami)@$(hostname)"
   ```

3. **Copy Public Key to VPS**
   - Ask user which VPS user to set up (root, moltbot, nexus, etc.)
   - Copy key using one of these methods:
     ```bash
     # Method 1: If ssh-copy-id is available
     ssh-copy-id -i ~/.ssh/id_ed25519.pub USER@srv1308064.hstgr.cloud

     # Method 2: Manual copy
     cat ~/.ssh/id_ed25519.pub | ssh USER@srv1308064.hstgr.cloud "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
     ```

4. **Fix Permissions**
   - On local machine:
     ```bash
     chmod 600 ~/.ssh/id_ed25519
     chmod 644 ~/.ssh/id_ed25519.pub
     ```
   - On VPS (via SSH):
     ```bash
     ssh USER@srv1308064.hstgr.cloud "chmod 700 ~/.ssh && chmod 600 ~/.ssh/authorized_keys"
     ```

5. **Test Connection**
   ```bash
   ssh -i ~/.ssh/id_ed25519 USER@srv1308064.hstgr.cloud "echo 'Connection successful!'"
   ```

6. **Troubleshoot if Connection Fails**
   - Check SSH verbose output: `ssh -vvv -i ~/.ssh/id_ed25519 USER@srv1308064.hstgr.cloud`
   - Common issues:
     - Wrong permissions on ~/.ssh or authorized_keys
     - Key with passphrase (needs removal: `ssh-keygen -p -f ~/.ssh/id_ed25519`)
     - Firewall blocking port 22
     - Wrong username
