## Context

The DYAI Kanban board (https://kanban-jet-seven-ashy.vercel.app) tracks tasks for CLI agents (Claude, Gemini, OpenClaw, Qwen). The task-runner polls Queue, agents work in Agent WIP, completed tasks go to Review, QA runner validates and moves to Done or back to Queue.

## Arguments

`$ARGUMENTS` — Optional: "detail" for full task list, or column name to focus on (e.g., "review", "queue", "wip").

## Your Task

Show a quick overview of the Kanban board state.

### Quick Overview (default)

```bash
ssh moltbot@srv1308064.hstgr.cloud 'curl -s https://kanban-jet-seven-ashy.vercel.app/api/board | node -e "
const d=require(\"fs\").readFileSync(\"/dev/stdin\",\"utf8\");
const b=JSON.parse(d);
console.log(\"\");
b.columns.forEach(c => {
  const count = (c.tasks||[]).length;
  const bar = \"█\".repeat(Math.min(count, 20));
  console.log(\`  \${c.title.padEnd(15)} \${String(count).padStart(3)} \${bar}\`);
});
console.log(\"\");
// Show agent activity
const wip = b.columns.find(c => c.title.toLowerCase().includes(\"wip\"));
if (wip && wip.tasks.length > 0) {
  console.log(\"  Agent WIP:\");
  wip.tasks.slice(0,5).forEach(t => {
    const desc = t.description || t.desc || \"\";
    const metaIdx = desc.indexOf(\"---agent-meta---\");
    let agent = \"?\";
    if (metaIdx !== -1) {
      try { agent = JSON.parse(desc.slice(metaIdx+16).trim()).agent || \"?\"; } catch {}
    }
    console.log(\`    [\${agent}] \${t.title.slice(0,60)}\`);
  });
  console.log(\"\");
}
"'
```

### Service Health (always include)

```bash
ssh moltbot@srv1308064.hstgr.cloud '
  echo "  Services:";
  for port_name in "3004:task-runner" "3006:qa-runner" "5678:n8n"; do
    port=${port_name%%:*};
    name=${port_name##*:};
    status=$(curl -s --max-time 2 -o /dev/null -w "%{http_code}" http://localhost:$port 2>/dev/null);
    if [ "$status" = "200" ]; then
      echo "    $name (:$port) — UP";
    else
      echo "    $name (:$port) — DOWN ($status)";
    fi;
  done
'
```
