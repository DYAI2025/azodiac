### Pre-Flight Checks

1. **RAM Check** — Abort if free RAM < 400MB:
   ```bash
   ssh -i ~/.ssh/id_ed25519 root@srv1308064.hstgr.cloud 'free -m | head -3; swapon --show'
   ```
   If no swap exists AND free < 1GB, create swap first:
   ```bash
   fallocate -l 2G /swapfile && chmod 600 /swapfile && mkswap /swapfile && swapon /swapfile && echo "/swapfile none swap sw 0 0" >> /etc/fstab
   ```

2. **Port Conflict Check:**

### Step 2: Manual Test

Run the service manually to verify it starts:
```bash
ssh moltbot@srv1308064.hstgr.cloud 'cd /home/moltbot/SERVICE_DIR && timeout 15 node service.js 2>&1'
```

If it fails, fix before proceeding. Do NOT create systemd unit for broken code.

### Step 3: Create Systemd Unit

```bash
ssh -i ~/.ssh/id_ed25519 root@srv1308064.hstgr.cloud 'cat > /etc/systemd/system/SERVICE_NAME.service << EOF
[Unit]
Description=SERVICE DESCRIPTION
After=network.target

[Service]
Type=simple
User=moltbot
WorkingDirectory=/home/moltbot/SERVICE_DIR
ExecStart=/usr/bin/node /home/moltbot/SERVICE_DIR/service.js
Restart=on-failure
RestartSec=10
Environment=NODE_ENV=production

[Install]
WantedBy=multi-user.target
EOF
systemctl daemon-reload && systemctl enable SERVICE_NAME && systemctl start SERVICE_NAME && systemctl status SERVICE_NAME --no-pager'
```

### Step 6: Add to Marvin Service-Guard

Use Python for reliable editing of the shell script:
```bash
ssh moltbot@srv1308064.hstgr.cloud 'python3 << "PYEOF"
content = open("/home/moltbot/marvin/skills/service-guard/service-guard.sh").read()

functions = """
check_SERVICENAME() {
    curl -s --max-time 3 localhost:PORT > /dev/null 2>&1
}

heal_SERVICENAME() {
    pkill -f "node.*service.js" 2>/dev/null
    sleep 1
    cd /home/moltbot/SERVICE_DIR
    nohup node service.js > /tmp/SERVICE_NAME.log 2>&1 &
    sleep 3
    check_SERVICENAME
}

"""

content = content.replace(
    "# ORPHAN PROCESS DETECTION",
    functions + "# ORPHAN PROCESS DETECTION"
)
content = content.replace(
    "guard_service \"hive-bridge\"",  # or last guard_service line
    "guard_service \"hive-bridge\" ...\n    guard_service \"SERVICE_NAME\" check_SERVICENAME heal_SERVICENAME || any_down=1"
)

open("/home/moltbot/marvin/skills/service-guard/service-guard.sh", "w").write(content)
print("OK")
PYEOF'
```

Validate syntax after editing:
```bash
ssh moltbot@srv1308064.hstgr.cloud 'bash -n /home/moltbot/marvin/skills/service-guard/service-guard.sh && echo "Syntax OK"'
```

### Guardrails

- **RAM first**: Always check free RAM before installing anything. n8n once OOM-crashed the whole server.
- **Manual test before systemd**: Never create a systemd unit for code that doesn't start manually.
- **Backup service-guard**: `cp service-guard.sh service-guard.sh.bak` before editing.
- **Syntax check**: Always `bash -n` the service-guard after editing.
- **Use moltbot user**: Services run as moltbot, not root. Systemd unit creation needs root.
