### Steps

1. **Check current state**:
   ```bash
   which rtk && rtk --version
   rtk init --show
   ```

2. **If rtk not found** — build and install:
   ```bash
   cargo install --path ~/claude/CLI-tokenreducter-master
   ```
   Verify: `which rtk && rtk --version`

3. **If hook not configured** — install globally:
   ```bash
   rtk init -g --auto-patch
   ```
   This installs:
   - Hook: `~/.claude/hooks/rtk-rewrite.sh`
   - RTK.md: `~/.claude/RTK.md` (slim, 10 lines)
   - `@RTK.md` reference in `~/.claude/CLAUDE.md`
   - PreToolUse entry in `~/.claude/settings.json`

4. **Verify hook** — confirm `rtk init --show` shows all green checkmarks

5. **Show economics**:
   ```bash
   rtk gain
   rtk discover --all --limit 10
   rtk cc-economics
   ```

6. **Report** summary of what was installed/verified and current savings stats

### Guardrails

- `jq` is required for the hook — check with `which jq`, install via `brew install jq` if missing
- RTK creates a `settings.json.bak` backup before patching — verify it exists after setup
- If `rtk --version` shows wrong version or `rtk gain` fails, user may have the wrong `rtk` package (reachingforthejack/rtk = Rust Type Kit, NOT this project)
- After hook installation, Claude Code needs a session restart for the hook to take effect
- The hook only rewrites the FIRST command in a chain — pipes and `&&` chains pass through
