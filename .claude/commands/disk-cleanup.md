## Context
You are helping free up disk space on a Mac when the disk is critically full or nearly full. This prevents system issues and allows installations to proceed.

## Your Task

Quickly identify and remove safe-to-delete files to free up disk space when the disk is critically low.

### Steps

1. **Check Current Disk Usage**
   ```bash
   df -h / | tail -1
   ```
   Show user the current usage percentage.

2. **Identify Space-Hogging Directories**
   ```bash
   du -sh ~/Downloads ~/Library/Caches ~/Library/Logs ~/.Trash ~/Library/Application\ Support 2>/dev/null | sort -hr
   ```

3. **Present Cleanup Options**
   Ask user which cleanup actions to perform:
   - Clear Library/Caches (usually 1-5GB)
   - Empty Trash
   - Clean Homebrew caches
   - Find large files (>1GB) for manual review
   - Clean Xcode derived data (if exists)
   - Clean npm/pnpm caches

4. **Clear Library Caches (if approved)**
   ```bash
   rm -rf ~/Library/Caches/* 2>/dev/null || true
   ```

   **Note:** Some files may have permission issues - this is normal. The command will skip them.

5. **Empty Trash (if approved)**
   ```bash
   rm -rf ~/.Trash/* 2>/dev/null || true
   ```

6. **Clean Homebrew Caches (if approved)**
   ```bash
   brew cleanup --prune=all -s 2>/dev/null || echo "Homebrew cleanup skipped"
   ```

7. **Find Large Files (if requested)**
   ```bash
   find ~ -type f -size +1G 2>/dev/null | head -20
   ```
   Present list to user for manual review.

8. **Clean Development Caches (if applicable)**
   - **Xcode:** `rm -rf ~/Library/Developer/Xcode/DerivedData/* 2>/dev/null`
   - **npm:** `npm cache clean --force 2>/dev/null`
   - **pnpm:** `pnpm store prune 2>/dev/null`
   - **Docker:** `docker system prune -af 2>/dev/null` (ask first!)

9. **Report Results**
   ```bash
   df -h / | tail -1
   ```
   Show before/after disk usage and total space freed.

### Guardrails
- **Never delete** without user confirmation for anything outside standard caches
- **Skip** files with permission errors (don't use sudo)
- **Warn** before Docker cleanup - it removes all images and containers
- **Library/Caches** is always safe to delete - apps recreate what they need
- **Don't delete** application-specific data or user documents

### Safe to Delete (Always)
- `~/Library/Caches/*` - App caches (recreated as needed)
- `~/Library/Logs/*` - Old log files
- `~/.Trash/*` - Trash contents
- Homebrew caches (`brew cleanup`)
- npm/pnpm caches

### Ask First
- Large files in ~ directory
- Docker images/containers
- Old downloads (user may want to review)
- Xcode derived data (if developer is actively coding)

### Never Delete Without Explicit Permission
- Anything in `~/Documents`, `~/Desktop`, `~/Pictures`, etc.
- Application data in `~/Library/Application Support`
- System files
- Git repositories

### Critical Disk Full (<1GB Free)

If disk is critically full (<1GB), prioritize immediate cleanup:
1. Clear Library/Caches immediately
2. Empty Trash
3. Clean Homebrew
4. Then assess other options

This usually frees 2-5GB quickly.
