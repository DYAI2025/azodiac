## Context

User frequently discovers Claude skill repos on GitHub and wants to evaluate whether they add value vs. overlap with existing capabilities, then install the useful ones.

## Arguments

- `$ARGUMENTS` — One or more GitHub repo URLs (space-separated), or "list" to show installed skills

## Your Task

Evaluate GitHub repos containing Claude skills, compare against existing capabilities, and install approved ones.

### Steps

1. **Inventory existing skills:**
   ```bash
   echo "=== Global Commands ===" && ls ~/.claude/commands/*.md 2>/dev/null | xargs -I{} basename {} .md
   echo "=== Skills ===" && ls ~/.claude/skills/*/index.json 2>/dev/null
   echo "=== Skills Unified ===" && ls ~/.claude/skills-unified/*/index.json 2>/dev/null
   ```

2. **For each repo URL:**
   - Clone to temp directory: `git clone --depth 1 <url> /tmp/skill-eval-$(basename <url> .git)`
   - Read README.md and any CLAUDE.md
   - List commands/skills it provides
   - Assess overlap with existing skills

3. **Present comparison table:**
   ```
   ┌──────────────────┬───────────┬──────────────────────────┬─────────────┐
   │  Repo            │  Skills   │  Overlap with existing   │  Recommend  │
   ├──────────────────┼───────────┼──────────────────────────┼─────────────┤
   │  repo-name       │  N skills │  Overlaps: X, Y          │  Install/Skip│
   └──────────────────┴───────────┴──────────────────────────┴─────────────┘
   ```

4. **Ask user** which repos to install

5. **Install approved skills:**
   - Copy command .md files to `~/.claude/commands/` (global) or project `.claude/commands/`
   - Copy skill directories to `~/.claude/skills/` if applicable
   - Handle name conflicts by asking user

6. **Cleanup:**
   - Remove temp clone directories
   - Report what was installed and where

### Guardrails

- Never overwrite existing skills without asking
- Always show what will be installed before doing it
- Clone with `--depth 1` to minimize bandwidth
- Clean up `/tmp/skill-eval-*` after installation
- If a repo has dependencies (npm, pip), warn the user before installing
