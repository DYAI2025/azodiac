## Context

User wants to install a tool from GitHub globally. The install method varies (shell script, npm, go install, Homebrew, binary release) so you must inspect the repo first before running anything.

## Your Task

Install the tool at the given GitHub URL globally on the current machine.

### Steps

1. **Inspect the repo** (clone to /tmp, read in parallel):
   - `git clone <url> /tmp/<repo-name> --depth 1`
   - Read: `README.md`, `package.json` / `go.mod` / `Cargo.toml`, `install.sh` / `Makefile`
   - Detect install method (priority order):
     1. `install.sh` or `install.ps1` → use official installer
     2. `package.json` with `bin` field → `npm install -g <package>` or npm pack+link
     3. `go.mod` → `go install github.com/...@latest`
     4. Cargo.toml → `cargo install --git <url>`
     5. GitHub Releases binary → download + chmod + move to /usr/local/bin
     6. Homebrew formula → `brew install`

2. **Run the installer**:
   - For shell scripts: download to /tmp first, inspect first 50 lines, then `bash /tmp/install.sh`
   - Prefer `--no-onboard` / `--non-interactive` / `-y` flags when available (avoids blocking on TTY)
   - If installer uses `git pull --rebase` internally and fails due to unstaged changes: `git -C <install-dir> checkout -- .` then retry
   - Watch for `set -e` scripts that silently abort — run with full output, not just `tail`

3. **Add to PATH if needed**:
   - Check `which <binary>` after install
   - If not found: symlink to `/usr/local/bin/` (writable without sudo on most Mac setups) or `/opt/homebrew/bin/`
   - Test: `[ -w /usr/local/bin ] && BIN=/usr/local/bin || BIN=/opt/homebrew/bin`

4. **If it's an MCP tool** (has MCP server, registers with Claude Code):
   - Run `/mcp-setup-verify` after install completes

5. **Verify**:
   - Confirm binary is in PATH: `which <tool>`
   - Run `<tool> --version` or `<tool> --help` to confirm it works
   - If the tool has a doctor/status command, run it

6. **Clean up**:
   - `rm -rf /tmp/<repo-name>`

### Guardrails

- **Never pipe `curl | bash` directly** — download to /tmp first, inspect, then run
- **Don't assume the default branch is `main`** — check `git branch -a` after cloning
- **Shell installer + `set -e`**: if the script exits early (git lock, missing dep, network), the later steps (PATH setup, config injection) silently don't run. Always check the full output.
- **npm global installs go to `npm config get prefix`/bin** — verify that's on PATH
