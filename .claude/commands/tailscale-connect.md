## Context
You are helping set up Tailscale VPN and connect to machines on the Tailscale network. This includes installation, authentication, and troubleshooting SSH connection issues specific to Tailscale.

## Your Task

Set up Tailscale, authenticate, find machines on the network, and establish working SSH connections.

### Steps

1. **Check Tailscale Installation**
   ```bash
   which tailscale 2>/dev/null && /Applications/Tailscale.app/Contents/MacOS/Tailscale version 2>/dev/null
   ```

   If not installed:
   - **macOS:** Install via Homebrew: `brew install --cask tailscale`
   - **Linux:** `curl -fsSL https://tailscale.com/install.sh | sh`

2. **Start and Authenticate Tailscale**
   ```bash
   # macOS
   /Applications/Tailscale.app/Contents/MacOS/Tailscale up

   # Linux
   sudo tailscale up
   ```

   Follow the authentication URL provided.

3. **List Available Machines**
   ```bash
   /Applications/Tailscale.app/Contents/MacOS/Tailscale status
   ```

   Show user:
   - Machine names and IPs
   - Online/offline status
   - Last seen time

4. **Test Connection to Target Machine**
   Ask user which machine to connect to, then:

   ```bash
   # Test basic connectivity
   ping -c 3 MACHINE_IP
   ```

5. **Handle SSH Connection**

   **Important:** Tailscale SSH has automatic user mapping that can cause issues. Use these approaches:

   **Approach A: Direct SSH (Recommended)**
   ```bash
   # Bypass Tailscale SSH user mapping
   ssh -o "ProxyCommand=none" -p 22 USERNAME@TAILSCALE_IP
   ```

   **Approach B: SSH via Hostname**
   ```bash
   ssh USERNAME@machine-name
   ```

6. **Fix SSH Host Key Issues**

   If "Host key verification failed":
   ```bash
   # Add host key for Tailscale IP
   ssh-keyscan -H TAILSCALE_IP >> ~/.ssh/known_hosts

   # Or use hostname
   ssh-keyscan -H machine-name >> ~/.ssh/known_hosts
   ```

7. **Troubleshoot Tailscale SSH User Mapping**

   If you see "tailscale: failed to look up local user":

   - This means Tailscale is trying to map your local username to remote system
   - **Solution:** Connect as root first to find available users:
     ```bash
     ssh root@TAILSCALE_IP "cat /etc/passwd | grep '/home' | cut -d: -f1"
     ```
   - Then connect with the correct username

8. **Verify Connection**
   ```bash
   ssh USERNAME@TAILSCALE_IP "echo 'Connection successful!' && hostname && whoami"
   ```

### Guardrails
- **Tailscale IPs** are in the 100.x.x.x range
- **Use root@IP** initially to bypass user mapping issues
- **Accept SSH host keys** automatically for Tailscale IPs (they're on your private network)
- If a machine shows "offline", check:
  - Is it powered on?
  - Is Tailscale running on that machine?
  - Network connectivity issues?

### Common Issues

**Issue: Tailscale not in PATH**
- On macOS: `/Applications/Tailscale.app/Contents/MacOS/Tailscale`
- Add to PATH or use full path

**Issue: "Logged out" status**
- Run `tailscale up` and re-authenticate
- Your session may have expired

**Issue: SSH user mapping fails**
- Tailscale SSH tries to map your local username
- Use `ssh root@IP` to bypass
- Or explicitly specify username: `ssh actual-username@IP`

**Issue: Can't resolve hostname**
- Use Tailscale IP directly (100.x.x.x)
- Check `tailscale status` for correct IP

**Issue: Connection refused on SSH**
- Check if SSH is running on remote machine
- Verify SSH port (default 22)
- Check firewall rules

### macOS vs Linux Differences

**macOS:**
- Tailscale installed via App or Homebrew cask
- CLI at `/Applications/Tailscale.app/Contents/MacOS/Tailscale`
- GUI app available in menu bar

**Linux:**
- Tailscale installed via package manager
- CLI at `/usr/bin/tailscale`
- Runs as systemd service: `sudo systemctl status tailscaled`
