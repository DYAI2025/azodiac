# Nuggets Memory — Auto-Load

Before starting work, check memory for relevant context:

```bash
nuggets recall "current project"
nuggets recall "user preferences"
```

## Quick Commands

| Command | Purpose |
|---------|---------|
| `nuggets recall "<query>"` | Search all memory |
| `nuggets remember <nugget> <key> <value>` | Store fact |
| `nuggets facts <nugget>` | List all facts |
| `nuggets list` | Show all nuggets |

## What to Remember

- Project locations
- User preferences (language, indent, style)
- Common commands
- Debug solutions
