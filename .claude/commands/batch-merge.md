## Context
User has multiple open PRs and wants them all merged without repeating "merge" for each one.

## Your Task

Merge all open PRs on the current repo in sequence.

### Steps

1. **List open PRs**
   ```bash
   gh pr list --state open --json number,title,author,headRefName,mergeable
   ```
   If no open PRs: report and stop.

2. **Show list to user** — number, title, branch, mergeable status

3. **Check for conflicts** — if any PR shows `mergeable: CONFLICTING`, list them and ask user how to handle before proceeding. Do NOT merge conflicting PRs automatically.

4. **Merge each mergeable PR in order**
   ```bash
   gh pr merge <number> --merge --delete-branch
   ```
   After each merge: confirm success before moving to next.

5. **Report** — which merged successfully, which were skipped and why.

### Guardrails
- Never force-merge (`--force`, `--admin`) without explicit user consent
- Skip PRs in CONFLICTING state — report them, don't touch them
- Never merge PRs targeting a branch other than main/master without noting it
- If a merge fails mid-run, stop and report — don't continue with remaining PRs until user decides
