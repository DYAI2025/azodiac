## Context

- Installed plugins: `~/.claude/plugins/installed_plugins.json`
- Known marketplaces: `~/.claude/plugins/known_marketplaces.json`
- Enabled plugins: `enabledPlugins` in `~/.claude/settings.json`
- Marketplace cache: `~/.claude/plugins/marketplaces/`

## Your Task

Audit all Claude Code plugins: find dead references, missing installations, and broken marketplaces. Then offer to fix issues.

### Steps

1. **Read state files** in parallel:
   - `~/.claude/plugins/installed_plugins.json`
   - `~/.claude/plugins/known_marketplaces.json`
   - `enabledPlugins` section from `~/.claude/settings.json`

2. **Cross-reference** three lists:
   - For each entry in `enabledPlugins`:
     - Is it in `installed_plugins.json`? If not → **not installed**
     - Does the marketplace (part after `@`) exist in `known_marketplaces.json`? If not → **marketplace missing**
   - For each installed plugin: is it enabled? If not → **installed but disabled**

3. **Validate marketplace repos** — for each marketplace with missing plugins:
   ```bash
   gh repo view <org>/<repo> 2>&1 | head -3
   ```
   - Repo doesn't exist → **dead reference**
   - Repo exists but no `.claude-plugin/marketplace.json` → **invalid format**

4. **Check plugin load status**:
   ```bash
   claude plugin list 2>&1
   ```
   Look for "failed to load" errors.

5. **Present findings** as a table:
   ```
   | Plugin | Marketplace | Installed | Enabled | Repo Exists | Status |
   ```

6. **Ask user** what to do:
   - Remove dead references from settings.json
   - Register missing marketplaces and install plugins
   - Disable broken plugins

7. **Execute** approved fixes:
   - Edit `settings.json` to remove dead `enabledPlugins` entries
   - `claude plugin marketplace add <org>/<repo>` for missing marketplaces
   - `claude plugin install <name>@<marketplace> --scope user` for missing plugins

### Guardrails

- Always back up settings.json before editing: `cp ~/.claude/settings.json ~/.claude/settings.json.audit-backup`
- Plugin marketplace names may differ from repo names (e.g., `DYAI2025-n-skills` vs `n-skills`)
- Some repos use `claude-plugin/` instead of `.claude-plugin/` — this is an invalid format, flag it
- When replacing marketplace references (e.g., `@DYAI2025-n-skills` → `@n-skills`), remove the old entry AND add the new one
- Never remove a plugin entry without user confirmation
