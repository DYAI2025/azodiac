## Context

Run at the end of any Bazodiac work session. Consolidates the three commands always invoked as a cluster at session close: `/ship`, `/claude-reflect:reflect-skills`, and `/nuggets` sprint-tasks sync.

## Your Task

Run the full end-of-session ceremony in order.

### Steps

1. **Test suite**
   ```bash
   npx vitest run 2>&1 | tail -5
   ```
   Report pass/fail count. If any tests fail — stop here and report. Do not ship.

2. **Ship uncommitted changes**
   - Run `git status` + `git diff` + `git log --oneline -5`
   - If there are uncommitted changes: stage relevant files, commit with a Conventional Commits message, push.
   - If nothing to ship: skip silently.

3. **Reflect skills**
   - Invoke `/claude-reflect:reflect-skills` to scan the current session for new patterns.
   - If new skill candidates are found, present them and ask for approval.

4. **Nuggets sync**
   - Read `3-code/tasks.md` and extract the current Done / In Progress / Pending counts.
   - Run `nuggets facts sprint-tasks` to see the stored snapshot.
   - If the stored snapshot is stale (counts differ), update it:
     ```bash
     nuggets forget sprint-tasks
     nuggets remember sprint-tasks done "<N>"
     nuggets remember sprint-tasks total "<N>"
     nuggets remember sprint-tasks remaining "<summary of open P1 tasks>"
     nuggets remember sprint-tasks updated "{YYYY-MM-DD}"
     ```
   - Report the updated snapshot.

5. **Summary**
   - Print a one-line session summary: what shipped, test count, any new skills.

### Guardrails
- Never ship if any test fails
- Never use `--force` or `--no-verify`
- Only update nuggets if the stored counts actually differ from current tasks.md
